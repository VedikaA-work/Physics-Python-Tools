## 🏗️ Mechanics Laboratory
*Exploring Material Science and Fluid Dynamics through code.*

#### **🔭 [Young's Modulus Module](./Mechanics/Youngs-Modulus)**
A specialized tool for calculating material stiffness ($\bf{E}$) and analyzing **Stress** ($\sigma$) to **Strain** ($\epsilon$) relationships.
*(Includes: Functional Code • LaTeX Documentation • Stress-Strain Diagram)*

#### **💧 [Surface Tension Module](./Mechanics/Surface-Tension)**
Analyzing the **Cohesive Forces** ($\bf{T}$) acting on liquid surfaces per unit length ($\bf{L}$).
*(Includes: Functional Code • Young-Laplace Diagram)*
